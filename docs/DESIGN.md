# 宇宙电台 · 界面规范（白&墨）

本文件是这个 Web 客户端**唯一**的视觉与交互规范。写任何页面或组件前先读它。
设计语言沿用我们其它项目沉淀下来的「极简」做法（`squirrel_mem_web_ui/docs/design/MINIMAL_WEB.md`、
`docs/UI.md`），并针对播客客户端做了取舍。**实现以 `src/index.css` 与 `src/theme.ts` 为准。**

## 0. 一句话

白底墨字，几乎没有底色；结构靠点线；一个强调色只给「正在播」；字号与字重是配给的，不是默认值。

## 1. 十条规则

0. **交互优先**：改样子不改「在哪一步完成」。原地能做的仍在原地做，不增加步数。
1. **一行一件事**：节目、单集、评论、分类都是行。左边图形，中间标题（可换行），行尾最多两个值。
   没有卡片、没有卡片套卡片、没有圆角矩形容器包裹内容。
2. **点线，不画盒子**：行与行之间是点线（`.dotted-rows` / `.dotted-top`，1.8px 圆点、6px 间距）。
   顶栏、左栏、播放条这类结构线用实线（`--border`）。不要 `divide-y`、`border-b` 画列表。
3. **一个强调色**（`--accent`，蓝或粉两版）：**只**出现在播放控件、播放进度、以及「正在播放」这类
   真的需要被强调的地方。标题、按钮、链接、选中态、图标都不要用它。
4. **主按钮是墨色**：主要动作（订阅、重试、登录）用墨色实心胶囊；次级动作是灰胶囊（无描边）；
   幽灵按钮悬停才有墨色 4% 的覆盖层。危险操作用浅红底红字。
5. **灰底只属于控件**：输入框、次按钮、胶囊、分段控件、封面占位。内容不用底色。
6. **选中是墨色**：列表里的当前项是墨色 600 文字（没有底色），或浅灰底（`--select`）+ 墨色 600。
   强调色不参与选中。
7. **字重是配给的**：400 正文与所有行标题；500 页面标题、按钮、页签、组标题；600 **只在字重本身
   表示状态时**（当前项、选中、未读）。不用 700/800。一个可见区域最多一处 600。
   层级不能只靠 500 对 400（Windows 上没有 500 这一档）：组标题比它下面的标签同时多字号与墨色。
8. **文字不截断**：行标题换行、行跟着长。只有空间固定的地方（封面卡的两行标题、播放条）用 `line-clamp`。
9. **严格左对齐，一条边线**：所有页面的标题、正文、按钮都从同一条起始边开始
   （内容区 `max-w-[1120px]` + `px-5 / lg:px-8`）。详情页的阅读列是 `max-w-[720px]`，仍然左对齐、
   不居中。可以居中的只有：播放器里的封面、对话框与登录表单块在屏幕上的位置。

## 4. 空间与形状

- 步长 4px。行上下 14px（`EpisodeRow` ≥ 72px），组与组之间 32–40px。
- 圆角：`sm 8`、`md 12`（小元素、封面缩略）、`lg 18`（输入、封面卡、图片）、`xl 22`（浮层）、
  `2xl 28`（底部面板）；按钮、胶囊、分段是全圆（`9999`）。
- 控件高度：按钮 40（小 32），胶囊 32，输入 40，顶栏 64，播放条 76，移动底栏 56。
- 图标尺寸：行内 15–17px，按钮内 13–15px。

## 6. 布局

```
≥1024px:  [ 左栏 232px ] [ 顶栏 64px + 内容区(≤1120) ]   ← 播放条固定，浮在左栏右侧之上
<1024px:  [ 顶栏 ] [ 内容区 ] [ 播放条 ] [ 移动底栏 56px ]
```

- 左栏（`Rail`）：品牌字标 + 行式导航（选中墨色 600，无底）+ 底部「主题色」与账号；「消息」行尾挂未读徽标。
- 顶栏（`TopBar`）：桌面端只有搜索框（`/` 键聚焦）与账号；移动端是字标 + 搜索入口 + 消息铃铛（未读徽标叠右上角）+ 账号。
- 播放条（`PlayerBar`）：封面 48 + 标题/节目 + 播放按钮（强调色）+ 进度 + 音量 + 展开/关闭。
  移动端浮在底栏之上，并保留顶部 2px 强调色进度线。
- 展开播放器（`PlayerSheet`）：大封面 + 走带（±15/30 秒）+ 进度 + 倍速 + 「查看单集详情」。
  移动端从底部升起，桌面端是右下角面板。**不要另外做一个常驻的右栏播放器**。
- 外壳：X 式三列 **左导航 248 + 中间内容 680 + 右侧栏 340 = 最大 1268px，整体居中**；<1280 收右栏、<1024 收左栏。超宽屏不再加宽。`n- 三列之间**不画分隔线**：用留白、对齐和字号层级区分栏目，不靠竖线切分。`n- 播放条出现时，左栏底部的点线要**与播放条上边缘同高**、并铺满左栏宽度，和播放条的顶边接成一条连续的分隔线；账号内容的中线仍对准播放条封面中线。`n- 播放条内容的左右内边距与页面内容一致（`px-4 / lg:px-5`），封面左边线与列表封面左边线对齐。`n- 播放条是平贴的分层：整条顶部一条 1px 边线（`--border`）分隔内容，不用投影/渐隐；出现时左栏底部的点线与这条边线同高，形成一条连续分隔线。`n- 播放条可见时，左栏底部那条点线会收掉（它和悬浮层打架）；没有播放条时点线仍是左栏底部的分隔线。
- 竖向对齐：左栏品牌中线 = 顶栏 64px 中线（32px）；播放中时左栏底部账号块的内容中线 = 播放条封面中线（账号块自带点线 padding，对齐要按内容而不是整块）。
- 详情页阅读列 720px，左对齐；浏览页（首页、分类、搜索）用货架（`.shelf`）与网格。
- 列表（榜单、收藏、订阅、节目单集）在 ≥1280 变两列行网格（`.row-grid`）；首页货架在 ≥1536 变网格，封面封顶 180–240px。
  收件箱是例外：**单列点线行 + 日期组标题**，不套 `.row-grid`（它是一份按时间读的流水）。

## 外观（light / dark）

- 两套外观：白&墨（默认，data-theme="light"）与夜间（data-theme="dark"）。
- 结构、间距、层级、圆角完全一致，只换语义变量的值：底压到近黑（--background: #0e0e0d）、
  墨反相成米白（--ink: #f2f1ec）、强调色各提亮一档（蓝 #3b82f6、粉 #f06595）。
- Ant Design 侧由 uildTheme(accent, appearance) 同步出 token（两套 palette）。
- 切换入口在左栏「外观」（日 / 夜），持久化在 xyz:appearance；首屏前由 index.html 内联脚本铺上，避免白闪。
- 调试/分享可直接用 URL：?theme=dark、?accent=pink（可叠加）。
## 单集页的播放模块

- **媒体头**：封面 104（≥sm 124）+ 节目名 + 标题 26/700 + 元信息 14，按钮不塞进这一层。
- **播放模块单独一块**：64 播放按钮 + 状态/时间 + 宽轨道进度条；它是页面上唯一的强调色位置。
- **次级动作**（收藏 / 分享）退到播放模块下方，用 ghost 样式，不参与播放的视觉竞争。
- **迷你播放条**：播放模块滚出视口后，顶部浮出「标题 + 播放」条（Spotify 单集页的做法）；
  已经开始播放本集时交给底部常驻播放条，不重复出现。
## 站点标记

- 左上角只有一个**小宇宙四线标记**（强调色圆角方块 + 白色线条），不再配「宇宙电台」文字；
  移动端顶栏同样只保留这个标记。

- 与单集页同一套骨架：**媒体头**（封面 104/124 + 标题 26/700 + 元信息 14）

## 声波进度条（WaveSeekbar）

- 播放进度不再用细线/细条，而是**轨道里的一排柱状声波**（单集页 96 根 / 56px 高，播放条 64 根 / 36px 高，
  展开播放器 84 根 / 56px 高）。
- 已播部分是强调色，未播是中性灰；播放时每根柱子做 scaleY 的错峰动画，暂停时冻结在当前相位
  （nimation-play-state）。
- **性能约定**：动画只用 CSS 	ransform（合成器处理，不触发 layout / paint），
  React 只在时间回调（约 4Hz）切换已播/未播颜色，**没有逐帧 setState、没有 rAF、没有 Web Audio 分析**；
  交互层是透明的原生 input[type=range]，键盘/读屏/拖拽保持原生行为；尊重 prefers-reduced-motion。
## 图标圆角

- 全站图标用 Lucide；在其自带的圆头线之外，再做一层统一处理（src/index.css）：
  svg.lucide 强制 stroke-linecap/linejoin: round，svg.lucide rect 的圆角半径统一提到 2.5（24 网格），
  把「分类」的方块、信封、播放/暂停这类几何形状也变圆。
- 自绘图形同样按圆角规则：播放三角是三个角都做大半径圆角的路径（不描边），暂停条是胶囊，
  品牌标记与分页圆点都带圆角。
- Ant Design 图标无法这样处理：它的 svg path 是固定几何，只支持 size/rotate/spin/style，没有圆角参数；
  所以没有回退到 antd 图标的计划。
## 播放启动顺序（避免「点了播放没反应」）

- 点击播放 → store 置 currentEpisode + isPlaying + isLoading → AudioPlayer 解析地址。
- **必须等 src 写入音频元素之后才允许调用 play()**：<audio> 首次挂载没有 src 时 play() 会被浏览器以
  NoSupportedSources 拒绝，若把这次拒绝当成失败打回暂停，就会出现「点一次不播、再点一次才播」。
  AudioPlayer 用 sourceEidRef 标记音源就绪，播放/暂停 effect 只在就绪后执行。
- 同一集重复点播放只恢复播放，不重置进度；关掉播放条会复位标记，下次播同一集会重新解析地址。
- isLoading 驱动播放按钮的 loading 态：解析地址、缓冲（waiting）时转圈，playing / canplay 后恢复；
  付费/私密单集拿不到地址时暂停并给出中文提示。
## 播放现场恢复 / 续听

- 启动时播放条直接出现**上次收听的那一集**，进度停在原位置，按钮是「播放」态（浏览器禁止无手势自动播放）。
- 恢复来源两级：先读本地快照（`localStorage: xyz:playback-state`）立刻显示；登录态就绪后再拉
  「最近收听 + 服务端进度」，按 `playedAt` 最后写入优先对账。只有远端确实更新时才 toast
  「已同步其他设备的播放进度：{单集名} {mm:ss}」。
- 进度保存时机：播放中每 10s、暂停、seek、页面隐藏/关闭；刷新/重开页面不丢现场。
- 同一集再点播放从恢复进度继续；切到别集才从 0 开始。恢复过程不能出现整页 loading 或骨架闪动。
## 播放条右侧的评论浮层

- 播放条右端的「关闭」已移除，换成**评论入口**：评论气泡图标 + 当前单集的评论数。
- 点击后在播放条上方浮出一块评论面板（桌面右下角 400px 卡片，移动端底部整宽），只做展示：
  昵称、时间/属地、正文（最多 4 行）、点赞与回复数；滚动到底自动加载更多。

## 发现页（X 式内容流）

- **布局**：页头大标题、副标题、「去榜单」按钮全部去掉；顶部是一条**吸顶内容流 tab**——贴内容区顶边，
  移动端在 64px 顶栏下方吸顶；tab 栏整条底边线，背景 92% 不透明 + blur，滚动时内容从下面穿过。
- **入口层级按使用频率映射**：高频内容流做一级 tab「为你推荐（默认）→ 关注 → 分类 → 精选」；
  榜单这种「有明确目的才去」的工具入口留在左栏主导航/移动端底栏，不占内容流 tab；搜索/账号/消息留顶栏。
- **tab 样式**：X 式——同字号，选中墨色 600 + 2px **强调色**下划线，未选中灰 500；横向可滚动、隐藏滚动条、不换行。
- **首屏**：只加载当前 tab；切 tab 保留已加载内容、不重复请求；每个 feed tab 独立分页；URL 同步 `?tab=following|category|featured`。
- **板块**（上游是多态 JSON，页面容错渲染）：
  - 活动位 / 快捷入口（DISCOVERY_HEADER）：上游是**分层素材**——`backgroundImage`（背景/纯色）、
    `leftImage.images`（左侧 1~N 个图标，`style=ROUNDED_CORNER` 时圆角）、`rightContent.image`
    （右侧透明底文字图）、`color.light/dark`（无背景图时的主题底色）。官方定位里这些入口**优先级低**，
    Web **所有尺寸**统一渲染成一行小胶囊（44px 高、宽度随内容、横滑且隐藏滚动条），
    不再用大 hero / 两列网格占首屏；右侧栏已删除与胶囊重复的「热门入口」，只保留榜单 / 分类 / 精选。
    透明底素材（图标 / 文字图）用 `SmartImage tone="none"`，不画占位底；夜间卡片保持
    `color.light` 浅色底，因为文字图是按浅色底设计的，用深色底会融在一起。
    外链在新窗口开；`cosmos://page.cos/webView?url=<https>` 解出内层 H5 地址后新窗口打开；
    其余 `cosmos://` 是 App 内页面，Web 点击时 toast 提示「该入口仅支持在小宇宙 App 内打开」，不静默失效。
  - 编辑精选（EDITOR_PICK）：`SectionHead` + 行列表 + 编辑推荐语一行（`pl-20 type-sub`）。
  - 单集推荐（DISCOVERY_EPISODE_RECOMMEND_V3）：`SectionHead` + 行列表 + 推荐语一行。
  - 视频播客（DISCOVERY_VIDEO_PODCAST）：`SectionHead` + 行列表。
  - 榜单（TOP_LIST）：每个榜单一个 `SectionHead`（「查看全部 →」对应 `/toplist/HOT|ROCK|NEW`）+ 前 3 名行（带名次）。
  - 分类块（EPISODE_CATEGORY_BLOCKS）：每个分类一个 `SectionHead`（「查看全部 →」进分类详情）+ 最多 4 条单集行；
    分类块条目可能只有 `{eid,title,podcast}`，**不显示播放按钮**（`EpisodeRow showPlay={false}`）。
  - 认不出的板块类型直接跳过，不用占位或报错。
- **加载 / 空 / 错**：每个 tab 独立骨架、`EmptyState`、中文错误 + 墨色重试；不会因为一个板块结构变化而整页崩。

## 加载与防抖

- **视口滚动条始终占位**：html { overflow-y: scroll; scrollbar-gutter: stable; } + 细滚动条样式。
  只留白槽位，不出现"内容加载中滚动条忽隐忽现"导致的整页左右抖动。
- **发现页首屏不再额外请求 `/discovery`**：右侧栏的快捷入口已删除，首屏只发当前 tab 的 `tab_*` 请求。
- **发现页不做路由懒加载**：避免「路由骨架 → 页面骨架 → 内容」三段跳。
- **启动校验用三列外壳骨架**（ShellSkeleton）：校验期间就画出左栏/内容/右栏的形状，校验完成后栏目位置不重排。
- 骨架高度尽量与真实内容一致（专题图比例、说明行、板块间距、行数），侧栏给分类/精选留占位。
